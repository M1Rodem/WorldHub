# WorldHub

WorldHub — система для совместной игры в Minecraft без постоянного игрового сервера.

## Основная идея

WorldHub объединяет игроков, обеспечивает совместное подключение к Minecraft-миру и управляет версиями мира по модели, похожей на Git/GitHub.

## Проект

- WorldHub Hub — основное приложение
- WorldHub Core — доменная логика
- WorldHub Sync — синхронизация и версии миров
- WorldHub Network — сетевой слой
- WorldHub Infrastructure — работа с файловой системой и внешними ресурсами
- WorldHub Minecraft Mod — интеграция с Minecraft

## MVP

Первый прототип рассчитан на двух игроков.

Основной сценарий:

1. Игрок создаёт или подключает Minecraft-мир.
2. Второй игрок подключается.
3. Игроки играют вместе.
4. После завершения создаётся новая версия мира.
5. Версия передаётся второму игроку.
6. Второй игрок может продолжить игру один.
7. После завершения создаётся следующая версия.
8. Первый игрок получает её и продолжает игру.

На первом этапе для сетевого соединения используется Radmin VPN или Hamachi.
